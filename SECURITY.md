# Security

Report suspected vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/tetracoralla/file-authority/security/advisories/new). Include affected versions, operating system and a minimal reproduction. Do not post credentials, private artifacts or exploitable details in a public issue.

Security fixes target the latest public release. Earlier releases may require upgrading. This library's documented guarantees cover its own operations; it is not a process sandbox and does not grant filesystem permissions.
